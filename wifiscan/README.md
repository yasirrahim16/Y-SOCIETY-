# Wifiscan by Yasir Rahim 🚀

An ultra-fast, multi-threaded network scanner for Linux/Kali Linux. 

## Features
- **Fast Scan:** Scans the network quickly using 50 threads.
- **Full Scan:** Discovers all devices (Online, Offline, Blocked).
- **MAC & Hostname:** Automatically resolves MAC addresses and hostnames.
